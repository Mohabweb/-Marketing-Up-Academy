# Marketing Up Academy

React + Vite + TypeScript + Framer Motion + Lucide. Arabic RTL, no backend.

```
npm install
npm run dev      # local
npm run build    # production build -> dist/
```

Deploy: push to GitHub, import in Vercel (framework preset: Vite, build `npm run build`, output `dist`).

All editable content (prices, courses, FAQ, contacts, photo captions) lives in `src/config.ts`.
Photos are in `public/heroes/`.
